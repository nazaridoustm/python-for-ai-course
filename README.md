## English

A complete course on Python for Artificial Intelligence, from the basics of the language to data science, machine learning and the classic algorithms of *Artificial Intelligence: A Modern Approach* (Russell & Norvig).

Every notebook is **executed and includes its outputs**, and runs from top to bottom with **Restart & Run All**. Code comments are in English; each topic comes with examples from industry, AI and expert systems.

### How to run
1. Install [Anaconda](https://www.anaconda.com/download) (recommended) or Python 3.10+.
2. Install the libraries:
   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```
3. Open a notebook in Jupyter, or open it in [Google Colab](https://colab.research.google.com) directly from GitHub.

## فارسی

دوره‌ای کامل در آموزش پایتون برای هوش مصنوعی، از مبانی زبان تا علم داده، یادگیری ماشین و الگوریتم‌های کلاسیک کتاب **«هوش مصنوعی: رهیافتی نوین»** (Russell و Norvig).

همهٔ نوت‌بوک‌ها **اجرا شده‌اند و خروجی دارند**، و با **Restart & Run All** از ابتدا تا انتها بدون خطا اجرا می‌شوند. کامنت‌های کد انگلیسی است و هر مبحث با مثال‌هایی از صنعت، هوش مصنوعی و سیستم‌های خبره همراه است.

### بخش‌های دوره
- **بخش ۱، مبانی پایتون** (پوشهٔ `01-python-basics`): جلسات ۱ تا ۱۴؛ متغیرها، ساختارهای داده، عملگرها، شرط‌ها، حلقه‌ها، توابع، مدیریت خطا، فایل‌ها و شیءگرایی.
- **بخش ۲، علم داده** (پوشهٔ `02-data-science`): جلسات ۱۵ تا ۱۹؛ NumPy، pandas و مصورسازی.
- **بخش ۳، یادگیری ماشین** (پوشهٔ `03-machine-learning`): جلسهٔ ۲۰؛ scikit-learn.
- **بخش ۴، کتاب AIMA** (پوشهٔ `04-aima-search`): جلسهٔ ۲۱؛ عامل‌های هوشمند و الگوریتم‌های جست‌وجو.

فهرست کامل نوت‌بوک‌ها در جدول بخش انگلیسی آمده است.
